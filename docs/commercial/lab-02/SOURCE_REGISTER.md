## Evidence discipline

The [comparison](COMPARISON.md) separates these vendor facts from fit hypotheses. [Lab 01 verification](../../VERIFICATION.md) is the source for this project's measured technical results. Discovery questions, draft scorecard thresholds, and workbook inputs are this portfolio's analysis or templates, not vendor promises. No paid security feature or real buyer evaluation was performed for Lab 02.

No numeric licence prices are asserted. A complete evaluation needs current written quotes for the actual configuration, including security products, compute, storage, support, and contract terms. The register is deliberately a dated selection of primary sources, not an exhaustive feature catalogue.
