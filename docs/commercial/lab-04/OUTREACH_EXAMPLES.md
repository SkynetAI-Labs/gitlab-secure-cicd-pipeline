## Proposed follow-up sequence—not an enrolled campaign

| Relative business day | Example | Conditional purpose |
| --- | --- | --- |
| 1 | E1 | First relevant, approved-channel approach in a hypothetical future process |
| 4 | L1 | Optional connection note only if that channel is appropriate and independently approved |
| 8 | C1 | Optional brief call only if an approved route exists |
| 13 | F1 | One clarification; no invented prior conversation or claimed result |
| 18 | F2 | Stop the sequence without manufacturing urgency |

This is a maximum five-step illustration, not a recommendation to use every channel. A decline, request to stop, clear mismatch, ownership conflict or missing channel approval stops the remaining steps. Do not switch channels to bypass a preference. E2/L2/C2 are alternate AppSec examples, not extra touches added to A01's sequence. No draft is assigned to deferred C01 or excluded D01.

[sequence-template.csv](sequence-template.csv) contains only relative timing and example IDs. Absolute dates, recipients and execution fields are empty or explicitly unsent. Actual identity, account ownership, approved process and channel requirements would need validation in a legitimate future role; this portfolio neither performs that validation for real people nor authorises contact.
