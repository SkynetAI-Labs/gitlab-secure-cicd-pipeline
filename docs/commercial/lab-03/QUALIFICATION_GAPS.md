## Next-action order

First validate the problem, sponsorship, authority and permission to involve the necessary stakeholders. Then agree criteria and an authorised evaluation scope while learning the assurance/purchasing route early. Confirm funding, decision method and dependencies before treating a technical result as a commercial commitment.

These are proposed priorities, not scheduled actions. No dates, meeting invitations, forecast probability, deal value or close category are assigned. If pain or sponsorship cannot be established, defer or stop. If existing tools meet the need at an acceptable cost, retaining them is a valid recommendation.

## Evidence hygiene

Each future update should record whether it is a direct buyer confirmation, approved document, second-hand report or seller hypothesis, with source/date and an accountable owner. Confidence should reflect evidence quality, not optimism. No actual buyer data is present in this repository. Review [DEAL_REVIEW.md](DEAL_REVIEW.md) for the concise interview application of this index.
